# Alanne Dias · Brand & Web Designer

Site de alannedias.com: Início, Sobre mim e Orçamento.

## Tema claro e escuro

O site abre no tema escuro original e oferece um botão fixo para alternar para a versão clara. O tema claro usa o cinza `#A3A3A3` da primeira seção da página inicial, com textos e cartões ajustados para contraste. A preferência é guardada no `localStorage` com a chave `alanne-theme` e compartilhada entre Início, Sobre e Orçamento. Caso o armazenamento esteja bloqueado, o botão continua funcionando durante a visita.

## Segurança e publicação

O projeto é estático e não possui login, tokens de acesso nem backend de autenticação. O orçamento é calculado no navegador e enviado como mensagem pré-preenchida ao WhatsApp, portanto os valores devem ser confirmados antes de qualquer cobrança. Não adicione senhas, credenciais, tokens de API ou informações privadas aos arquivos publicados. Proteja a conta GitHub com autenticação em dois fatores e mantenha HTTPS ativado na hospedagem.
